Sistema em Crud PHP

Desenvolvimento de uma aplicação web CRUD utilizando PHP e banco de dados, permitindo o cadastro, consulta, atualização e exclusão de registros de forma dinâmica e organizada.O projeto foi desenvolvido com o objetivo de aprimorar conhecimentos em desenvolvimento web, integração com banco de dados e implementação das operações fundamentais de manipulação de dados em aplicações reais.

Principais competências desenvolvidas:

• Desenvolvimento web com PHP
• Integração com banco de dados MySQL
• Operações CRUD (Create, Read, Update e Delete)
• Manipulação e validação de dados
• Estruturação de aplicações web
• Versionamento de código com Git e GitHub
